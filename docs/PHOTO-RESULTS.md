# Фото и фотокарусели — 2 октября 2026

Статус: предварительная реализация подключена к Save и Chrome Downloads. Сквозные проверки на синтетических страницах проходят; на двух реальных публикациях проверены DOM и получение файлов через браузерный инструмент, но не весь путь кнопки расширения.

## Что подтверждено на предоставленных публикациях

- Авторизованный встроенный браузер открывает обе публикации. Чистый тестовый Chromium показывает региональное ограничение для первой и недоступность второй. Cookies и профиль пользователя не переносились.
- Первая публикация — четыре фотослайда. Пройдены позиции 1–4 штатными кнопками, последняя позиция имеет только «Назад». URL содержит img_index. В DOM наблюдаются UL/LI, смещения translateX и отдельный элемент шириной 1 px на правом конце; внешний контейнер ограничивает видимую область через overflow-x:auto.
- Вторая публикация — одно основное фото; изображения рекомендаций находятся в ссылках и исключаются из выбора.
- Получены и проверены через ffprobe JPEG 1638×2048 и JPEG 480×288. Сохранение выполнено браузерным downloadMedia, не API установленного расширения. Наблюдаемый слайд не содержит srcset; более высокое разрешение для него не подтверждено.
- Устойчивые идентификаторы слайдов не обнаружены. Временный путь CDN не превращается в ID.

## Реализация

Кнопка «Save фото» доступна на /p/. Операция резервируется до сбора. Карусель возвращается к началу и собирается в порядке позиций. Полнота требует согласованного количества, рассчитанного по наблюдаемой геометрии, и последовательного сбора всех позиций. Исчезновение «Далее» до ожидаемого конца даёт partial. Неподтверждённая разметка отклоняется.

Фото получаются в изолированном контексте без credentials и перенаправлений. Общий объём ограничен 64 МиБ, число элементов — 50, ожидание слайда — 10 сек., сбор/получение — 120 сек. Формат JPEG/PNG/WebP определяется по сигнатуре. В Chrome передаются Blob URL; они остаются живыми до подтверждения безопасного освобождения. Подтверждение успеха — Downloads complete. В IndexedDB сохраняются метаданные и имена, без временных URL и медиабайтов.

Ручное вмешательство во время сбора, отмена и смена публикации останавливают работу. Save не дублирует завершённое; повторное скачивание выполняется явно. Докачка по номерам слайдов не включена. Карусели с видео пока не поддержаны полностью: они не должны получать ложный полный успех.

## Проверки и остаток

- 145 unit tests, 17 browser integration tests; typecheck, lint, build.
- Браузерные тесты используют production dist, настоящий MSE для Reel и Chrome Downloads для фото. Проверены одиночное фото, четыре файла карусели со стартом с третьего слайда, отмена, порядок имён и отсутствие временных URL в журнале. Содержимое скачанных фото совпадает с тестовым оригиналом.
- Независимое ревью выявило гонку Cancel → Save. Исправлено: новый запуск ждёт завершения предыдущего; запоздалый status не меняет другую операцию. Регрессионный тест подтвердил воспроизведение до исправления.
- Для реальной приёмки необходимо загрузить ZIP в Chrome с доступом к этим публикациям и проверить кнопку Save фото. Встроенный браузер не имеет установленной тестовой сборки. Нет утверждения о полной проверке реального расширения на этих двух публикациях.
- Разметка и русский язык навигации ограничены наблюдавшимися вариантами. Полная библиотека, устойчивые ID/докачка и смешанные карусели остаются отдельными задачами.
