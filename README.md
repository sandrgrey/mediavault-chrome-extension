# MediaVault — предварительная сборка

Локальное Chrome MV3 расширение. Сохраняет текущий поддерживаемый Instagram Reel в MP4 без сервера и перекодирования.

## Установка

1. Выполнить `npm install`, затем `npm run build`.
2. В Chrome открыть управление расширениями, включить режим разработчика.
3. Нажать «Загрузить распакованное расширение» и выбрать папку `dist`.
4. Открыть конкретный Reel. Кнопка **Save Reel** перезагрузит страницу один раз.
5. Дождаться «MP4 сохранён.». Файл появится в Downloads/MediaVault. Не закрывать вкладку во время сохранения.

Если установлен готовый ZIP, распаковать его и выбрать папку с manifest.json вместо dist.

## Что проверено

- Захват начинается после Save, ограничен 120 секундами и 16 МиБ; полные входы до 64 МиБ.
- Раздельные видео и звук сопоставляются с активным MSE-плеером по данным буферов.
- Отмена, смена публикации, перезапуск worker и неопределённый результат не запускают повторное скачивание автоматически.
- Успех означает Chrome Downloads complete. В журнал не записываются временные медиассылки, cookies или байты файлов.
- Разрешения: downloads, storage и только www.instagram.com. Внешнего сервера нет.

## Ограничения

Это не универсальный загрузчик Instagram. Проверены два реальных Reel: с раздельными видео/звуком и без звука. Для второго режима нужен видимый признак «В видео нет звука» рядом с текущим плеером и ровно одна видеодорожка без аудио в полном MP4. Пока поддержан только этот наблюдавшийся русский текст Instagram; другие локализации не подтверждены. Отсутствия аудиобуфера или тайм-аута недостаточно для сохранения без звука.

Поддерживаются только явно проверенные CDN hosts. Неоднозначные или неподдержанные источники отклоняются. Фото, карусели, полноценный интерфейс библиотеки и retry без устойчивого media ID ещё не готовы. Для повторного скачивания требуется явное действие; существующий файл не перезаписывается.

Через страницу расширения доступна отдельная ручная форма объединения локальных MP4-дорожек.
